# personal ethics statement
Ethics in AI is not only about intention, but also about making those intentions actions. Vague principles surrounding what should and should not be are not enough, and I want to work to create more regulated and concreate guidelines. Guidelines should be treated like requirements, and should be clear, testable, and integrated properly. I think it is really important to know how to take accountability for how a system should be built and then used, and not just assume that it will also be fine.
